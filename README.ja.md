# Turing Award Lectures（チューリング賞講演）

ACM A.M. Turing Award の全ての受賞者は講演を行ってきており、その多くは単なる歴史的好奇心ではなく、コンピュータ科学について本当に優れた著作として今日でも価値を保っています。このリストの歴史の大部分において、講演が発表された唯一の場所は [`dl.acm.org`](https://dl.acm.org/)（ログイン壁の背後）でした。このため、このテーブルが存在します。各受賞者（1966～2025年）へのリンクが、実際に無料でアクセスできるバージョンを指しています。

**他言語版:** [English](./README.md) · [詳細な受賞者紹介 (Biographical Overview)](./LAUREATES.ja.md)

---

## 講演へのアクセス方法

情報源の優先順位：著者自身のサイトまたは機関のアーカイブ、オープンな発行者/会場ページ（例えばオープンなCACM記事）、正当な公開アーカイブ（Internet Archive）、大学のコース/図書館ページがPDFをホストしているもの。意図的に除外されたもの：著作権のある『ACM Turing Award Lectures』書のスキャン版を、機関または著者の支援なしに公開している非提携の個人サイト（例：jdl.link、rkka21.ru）。これらの合法性が不確実なため、それらが検索で見つかった唯一の「無料」バージョンであっても除外されます。講演が正式に出版されたことがない場合、またはクリーンなものが見つけられない場合、テーブルはそれを疑わしいリンクの代わりに示します。

[ACMは2026年1月1日にデジタルライブラリ全体をオープンアクセスにしました](https://news.slashdot.org/story/25/12/19/168225/acm-to-make-its-entire-digital-library-open-access-starting-january-2026)。ほとんどの [`dl.acm.org`](https://dl.acm.org/) リンクはログインなしで機能するようになりました。書かれた講演が確認されている場合、このテーブルはそのDOIに直接リンクし、[ACMの公式講演リスト](https://amturing.acm.org/lectures.cfm)に対して相互参照されています。「無料版が見つかりません」とまだマークされている行は、その講演が公式リストにもありません。つまり、正式に出版または記録されたことがない可能性があります。
